# Setup & Run Guide

A step-by-step guide to get the project running from scratch.

---

## Prerequisites

- Python **3.10** (recommended — tested with TF 2.13+ and PyTorch 2.x)
- Git
- ~30 GB free disk space (for the full Kaggle dataset)

---

## Step 1 — Clone the repo

```bash
git clone https://github.com/jboiie/historic-artwork-forgery-detection.git
cd historic-artwork-forgery-detection
```

---

## Step 2 — Create a virtual environment

```bash
python -m venv venv

# Windows
venv\Scripts\activate

# macOS / Linux
source venv/bin/activate
```

---

## Step 3 — Install dependencies

`requirements.txt` covers only what the deployed Streamlit app needs (torch, torchvision, streamlit, pandas, scikit-learn, Pillow, numpy). Training, EDA, and the GAN pipeline need the additional packages in `requirements-train.txt` (tensorflow, matplotlib, seaborn, opencv-python, joblib, kagglehub, tqdm).

```bash
pip install --upgrade pip
pip install -r requirements.txt -r requirements-train.txt
```

> Just running the Streamlit app (Step 8)? `pip install -r requirements.txt` alone is enough.

> **GPU users:** Install PyTorch with CUDA support first from https://pytorch.org/get-started/locally/, then run the install command above.

---

## Step 4 — Download the dataset

We have provided a script to download the dataset using the `kagglehub` library.

```bash
pip install kagglehub
python download_dataset.py
```

This will download the entire Kaggle dataset (~30GB full, or just the image subset) and copy the images to `data/historic-art/complete/artwork/` and metadata CSVs to `data/historic-art/complete/`.


---

## Step 5 — Link images to metadata

```bash
python utils/link_images_to_metadata.py
```

Creates `data/merged_artwork_metadata.csv` — the combined metadata + image paths file used by all training scripts.

---

## Step 6 — Run EDA (optional, but recommended)

```bash
python eda/eda_artwork.py
```

Generates distribution plots for artists, periods, nationalities.

---

## Step 7 — Train the CNN Artist Classifier

Trains a ResNet-50 model to classify artworks by artist using PyTorch.

```bash
# From the project root:
python prediction/combined.py
```

Outputs:
- `models/best_artist_classifier_cnn.pth` — best model weights
- `models/label_encoder.pkl` — artist label encoder
- `cnn_classification_report.txt` — per-class accuracy report
- `confusion_matrix.png` — confusion matrix heatmap

---

## Step 8 — Run the Streamlit App

```bash
streamlit run prediction/app.py
```

Upload any painting image and get:
- Predicted artist name
- Artist birth/death period
- Nationality

---

## Step 9 — GAN Pipeline (Forgery Detection)

The GAN pipeline is separate and uses TensorFlow.

```bash
# 1. Sample images for GAN training
python GAN/extract_images.py

# 2. Preprocess / augment those images
python GAN/preprocess_images.py

# 3. Train the GAN
python GAN/train_gan.py
```

## Common Issues

| Error | Fix |
|-------|-----|
| `ModuleNotFoundError: tensorflow_addons` | Already removed — update your env: `pip install -r requirements.txt` |
| `FileNotFoundError: images/sample/...` | Download images from Kaggle (Step 4) |
| `FileNotFoundError: data/merged_artwork_metadata.csv` | Run `utils/link_images_to_metadata.py` first (Step 5) |
| CUDA out of memory | Reduce `BATCH_SIZE` in the training script config |
| `label_encoder.pkl` not found | Run `prediction/combined.py` to train and generate it |
